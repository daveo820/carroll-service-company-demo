# Carroll Service Company: concept site by LuminArch

A pitch demo for Carroll Service Company, Inc. (Garner, NC, heating and air since 1973). **Not the official site.** Noindexed, blocked in robots.txt, and labeled with a concept banner on every page.

- Live preview: https://daveo820.github.io/carroll-service-company-demo/
- Pages: home, services, reviews, the family, free estimate, 404
- Stack: static HTML, CSS and one small JS file, generated by `build.py` (run `python3 build.py`).
- Facts and sources: `FACTS_LOG.md`. Design: `DESIGN_DNA.md`. Audit and competitors: `market-research.md`.
- Screenshots: `screenshots/index-desktop-fold.png` and `screenshots/index-mobile-fold.png`.

Before launch: the Carrolls confirm names and roles, the license number is checked on the state board, the placeholders are filled, the form gets connected, and the concept banner and noindex come off.
